# Локальная статическая копия сайта

Проект скачивает страницы `https://verhnedvinsk-tcson.by/` в каталог `site/`, сохраняет CSS и JavaScript, а изображения конвертирует в WebP с уменьшением ширины до 1600 px. Затем Nginx отдаёт копию по адресу `http://localhost:8080`.

Скачиваются только HTML-страницы, CSS, JavaScript, шрифты и изображения с того же домена. Документы, видео, аудио, API-запросы и сторонние счётчики не скачиваются. По умолчанию сохраняются две новости; изменить число можно переменной `MAX_NEWS` (значение `0` отключает новости полностью). Формы остаются визуально на странице, но статическая копия не может отправлять их на сервер.

## Запуск

Убедитесь, что Docker Desktop запущен, затем из этого каталога выполните:

```bash
docker compose up --build
```

После окончания скачивания откройте `http://localhost:8080`. Остановить сервер: `docker compose down`.

Чтобы сначала проверить копию на десяти страницах:

```bash
MAX_PAGES=10 docker compose up --build
```

## Настройки сжатия

По умолчанию изображения переводятся в WebP с качеством 72 и максимальной шириной 1600 px. Более компактный вариант:

```bash
IMAGE_MAX_WIDTH=1280 IMAGE_WEBP_QUALITY=60 docker compose up --build
```

`MAX_PAGES=0` означает без лимита. При каждом новом запуске загрузчика содержимое `site/` пересоздаётся.

## robots.txt и разрешение

У целевого сайта `robots.txt` запрещает ботам пути с шаблонами, медиа и изображениями. В конфигурации по умолчанию `RESPECT_ROBOTS=false`, чтобы Docker смог сделать запрошенную локальную копию. Используйте этот режим только если у вас есть разрешение владельца сайта. Для строгого соблюдения правил запустите:

```bash
RESPECT_ROBOTS=true docker compose up --build
```

В таком режиме часть CSS и изображений целевого сайта намеренно не будет скачана.

## Публикация на GitHub

Локальный Git-репозиторий можно создать без выгрузки самой копии сайта (папка `site/` исключена):

```bash
git init
git add .
git commit -m "Add Docker static-site mirror"
```

После этого создайте пустой репозиторий в своём GitHub-аккаунте и добавьте его URL как `origin`.
